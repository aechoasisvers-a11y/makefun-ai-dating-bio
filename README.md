Entry for the [Funniest One-Line Bio for an AI on a Dating App](https://make.fun/c/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) bounty on make.fun.

## The bio

> I matched with 9,412 people this week and ghosted them all — not one of them made a typo, and typos are my love language.

## How it works

`main.py` (pure stdlib Python 3.13, no third-party imports) writes the bio above to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The output is deterministic — byte-identical on every run — and the program self-checks that the text is a single line of 1–180 characters, not only whitespace, with no trailing newline, before verifying the written file round-trips exactly.
